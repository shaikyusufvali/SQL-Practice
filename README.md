# 🗄️ SQL Programs Collection

A comprehensive collection of SQL programs for beginners, students, and interview preparation. This repository covers SQL fundamentals, database operations, joins, functions, constraints, and advanced queries with easy-to-understand examples.

* Database Creation
* Table Creation
* Insert Records
* Select Queries

* ORDER BY
* DISTINCT

* DELETE

  * SUM()
  * AVG()
  * MAX()
  * MIN()

* HAVING
* LIKE
* BETWEEN
* IN
* Joins

  * INNER JOIN
  * LEFT JOIN

  * FULL OUTER JOIN

  * NOT NULL

## 🚀 How to Use

1. Clone the repository

```bash
git clone https://github.com/your-username/SQL-Programs.git
```

2. Open MySQL Workbench, SQL Server, Oracle SQL Developer, or PostgreSQL.

3. Execute the SQL files one by one.

4. Observe the output and practice modifying the queries.
